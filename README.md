Реализована модульная архитектура приложения со строгим разделением ответственности.

Реализован парсер веб-страницы на базе библиотеки Jsoup.

Разработан класс поиска файлов: рекурсивный обход вложенных папок с фильтрацией по расширениям *.json и *.csv.

Реализованы отдельные парсеры для файлов форматов JSON и CSV: для JSON — десериализация массива объектов в Java-объекты через библиотеку Gson, для CSV — ручной разбор строк с учётом заголовка файла и разделителя ;; оба парсера принимают путь к файлу и возвращают список объектов единой модели данных.

Создан класс-агрегатор для сборки и записи результатов: добавление данных из всех источников через методы-«сеттеры» и генерация двух выходных файлов — map.json со списком станций по линиям и перечнем линий в формате проекта SPBMetro, а также stations.json со свойствами станций (название, линия, дата открытия, глубина, наличие перехода); обеспечено сопоставление данных из файлов со станциями с веб-страницы по нормализованному имени станции, а отсутствие каких-либо свойств корректно обрабатывается — соответствующий ключ в JSON не записывается.

Обеспечена обработка нештатных ситуаций: парсинг числовых значений (номера линий, глубины) защищён от некорректного формата, нормализация имён станций (регистр, буква «ё», лишние пробелы) повышает точность сопоставления данных из разных источников, ошибки ввода-вывода пробрасываются с понятным контекстом.

Подключена система сборки Maven и структурирован проект по классам в соответствии с принципом единственной ответственности; работа каждого класса проверялась поэтапно через контрольный вывод в main — от парсинга сайта до итоговой генерации обоих JSON-файлов.

Реализован поисковик по названиям линий или станции.

Стек: Java, Maven, Jsoup, Gson, Jackson, java.nio.file, JSON-сериализация, Git
